# files/ — 资料文件存放处

把课件、试卷、视频等文件按分类放进对应的文件夹：

- `课件/` —— PPT、PDF 课件
- `试卷/` —— 试卷、答案
- `实验视频/` —— 实验演示视频
- `讲义/` —— 讲义、学案

放好之后，去 `data/resources.js` 的 `RESOURCES` 里加一条记录，
`file` 字段写相对路径，例如：`files/课件/第一章.pptx`。

注意：
- 文件名尽量用英文或拼音，避免空格；中文文件名在部分环境下链接可能出问题。
- 单个文件建议不超过 25MB，整个仓库建议不超过 1GB（GitHub 的软性限制）。
- 大视频建议传到 B 站设为公开/私享，在 `file` 里直接填视频网址即可。
